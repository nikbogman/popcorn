# Popcorn

An all-in-one app for watching and tracking movies in my home setup.

## Features

### 1. Movie lists ([spec](https://github.com/nikbogman/watchlist/issues/1))

- As a user, I want to search movies by title and open one to see its info.
- As a user, I want to add a movie to _To watch_ so I remember to see it.
- As a user, I want to mark a movie _Watched_ so I keep a dated log of what I've seen.
- As a user, I want to mark a watched movie as _Favourite_ so I can find the ones I loved.
- As a user, I want to browse my _To watch_, _Watched_ and _Favourites_ lists.
- As a user, I want to log in so only I can see and change my lists.

### 2. Explore

- As a user, I want to discover movies beyond searching by title, so I can find something to watch when I have nothing in mind.

### 3. Remote control

- As a user, I want to control playback on my home setup from the app. (Details TBD.)

### 4. Movie finder (chat)

- As a user, when an Instagram reel shows a movie scene I don't recognise, I want to share the reel to the app so it finds the title for me.
- As a user, I want the app to read the reel's comments, where the title is usually named, and return the matching movie in a chat-like page.

### 5. Movie dating (future)

- As a user, I want to swipe through movie suggestions like a dating app, so choosing what to watch is quick:
  - swipe right to add to _To watch_
  - swipe left to dismiss for now
  - swipe up to see the movie's info
  - swipe down to remove it from suggestions for good
